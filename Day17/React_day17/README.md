# Students Data Table

A simple React application that displays students' data in a responsive table.

## About The Project

This project is a single-page React application designed to display university students'information in a clear and organized table.

The table displays different information about each student, such as:

- Student ID
- Student Name
- Student Age
- Student Email
- Student Faculty
- Student Level
- Student GPA
- Student City

## Technologies

- React.js
- JavaScript
- HTML5
- CSS
- Bootstrap5

## Features

- Display students'data in a table
- Responsive design
- Clean and simple UI
- Reusable React components
